Latar Belakang & Minat

Saya merupakan lulusan D4 Teknologi Rekayasa Multimedia yang memiliki minat besar pada perancangan antarmuka pengguna (UI/UX) dan implementasi frontend web. Proyek Utama (Web Application)

Website Pencarian & Pengajuan PKL Siswa SMK

Aplikasi web yang dirancang untuk mempermudah siswa SMK menemukan lowongan Praktik Kerja Lapangan (PKL), melakukan pengajuan lamaran daring, serta membantu pihak pengelola memverifikasi calon peserta secara transparan.

Masalah:

Pencarian tempat PKL manual menyulitkan siswa memantau kepastian lamaran dan membebani pengelola dalam menyortir data pendaftar.

Solusi:

Membangun portal web terpadu dengan autentikasi siswa, formulir lamaran online, dan dasbor seleksi/persetujuan (ACC).

Peran Saya:

Frontend Developer & Database Designer (Membangun antarmuka web interaktif serta merancang skema relasi database di MySQL).

Fitur Kunci:
  • Autentikasi & manajemen akun siswa
  • Sistem pengajuan/melamar PKL
  • Fitur persetujuan / verifikasi (ACC) pendaftar
Laravel MySQL PHP HTML / CSS Tailwind CSS
